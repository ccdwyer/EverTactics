===============================================================================
FFT SPRITE TOOLKIT - ACT PALETTE FILES
===============================================================================

This folder contains extracted 16-color palettes in Adobe Color Table (.ACT)
format. These files can be edited in Photoshop (Image → Mode → Color Table),
GIMP, or other image editors.

Recommendation: PalEdit @ https://github.com/benbaker76/PalEdit/releases

-------------------------------------------------------------------------------
FILE NAMING FORMAT
-------------------------------------------------------------------------------

sprite_{NUMBER}_{TYPE}_palette_{INDEX}.act

Examples:
  sprite_830_battle_palette_00.act   → Ramza, Slot 1 battle palette
  sprite_830_portrait_palette_08.act → Ramza, Slot 1 portrait palette
  sprite_845_battle_palette_02.act   → Red Chocobo, variant 3

-------------------------------------------------------------------------------
PALETTE SYSTEM OVERVIEW
-------------------------------------------------------------------------------

Each sprite has 16 palettes total:
  • Palettes 0-7:  Battle/Formation screen colors (8 slots)
  • Palettes 8-15: Portrait colors (8 slots)

Battle and portrait palettes are PAIRED by slot number:
  • Slot 1 uses palette 0 (battle) + palette 8 (portrait)
  • Slot 2 uses palette 1 (battle) + palette 9 (portrait)
  • ... and so on through Slot 8

-------------------------------------------------------------------------------
PALETTE USAGE BY SPRITE TYPE
-------------------------------------------------------------------------------

1. STORY CHARACTERS (Ramza, Delita, Agrias, etc.)
   └─ Uses Slot 1 only (palette 0 + 8)
   └─ Other slots (2-8) are EMPTY (all black, unused)

2. MONSTERS (Chocobos, Goblins, Bombs, etc.)
   └─ NOT team-based, use COLOR VARIANTS instead
   └─ Typically 3-4 variants:
      • Palette 0 → Yellow Chocobo
      • Palette 1 → Black Chocobo
      • Palette 2 → Red Chocobo
      • Palette 3 → (unused or 4th variant)
   └─ Palettes 4-7 are EMPTY (all black, unused)
   └─ Portraits (8-15) usually EMPTY (monsters don't have portraits)

3. GENERIC HUMAN CLASSES (Squire, Knight, Archer, etc.)
   └─ Uses 5 TEAM COLORS:
      • Palette 0 → Blue team (player default)
      • Palette 1 → Red team
      • Palette 2 → Green team
      • Palette 3 → Yellow team
      • Palette 4 → Purple team
   └─ Palettes 5-7 are EMPTY (only 5 teams in game)
   └─ Portraits (8-15):
      • Palette 8-12 → Team colors (5 variants)
      • Palette 13-15 → EMPTY (unused)

-------------------------------------------------------------------------------
EMPTY PALETTES (MODDING OPPORTUNITY!)
-------------------------------------------------------------------------------

Many palettes are all black because they're unused by the base game:
  • Story characters: Only slot 1 used, slots 2-8 empty
  • Monsters: Only 3-4 variants, remaining slots empty
  • Generic classes: Only 5 team colors, slots 6-8 empty

Game only loads palettes that have corresponding team/variant data
in battle scripts. Adding custom palettes here won't show in-game unless you
also mod the game's unit data (advanced modding, outside toolkit scope).

-------------------------------------------------------------------------------
TROUBLESHOOTING
-------------------------------------------------------------------------------

Q: I edited an ACT file but colors didn't change in-game
A: Make sure you:
   1. Saved the .ACT file (don't just edit and close)
   2. Ran "Convert and Package" to generate SPR files
   3. Enabled the mod in Reloaded-II

Q: All my palettes are black (empty)
A: This is normal for unused slots. See "EMPTY PALETTES" section above.
   You can add custom colors, but they won't show in-game without modding
   the unit data (outside toolkit scope).
